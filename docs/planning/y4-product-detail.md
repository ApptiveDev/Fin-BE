# Y4 상품 상세, 수익률 계산기, 아웃링크 신청

> 원본: 노션 「Y4 상품 상세 페이지 PRD」, 「Y4-1 수익률 계산기 기능 PRD」, 「Y4-2 아웃링크 신청 기능 PRD」 (2026-06)

## Y4 상품 상세

### 개요

추천 리스트에서 상품을 누르면, 상품 유형(정부/은행)에 맞는 의사결정 정보를 보여주고 **리스트의 정렬 기준이었던 숫자를 상세에서 분해해** "그래서 내가 얼마를 받는가"에 답한다. 그다음 신청(아웃링크)으로 연결한다.

- 정부형: 기여금 연 환산 수익률, 예상 만기 기여금 총액, 매칭 분해. 계산기 없음.
- 은행형: 기본금리, 최고금리, 내가 받을 수 있는 금리, 충족·미충족 우대조건. 계산기 버튼 있음.
- 1·2단계 입력값을 상세 표시와 계산기 프리필에 다시 써서 재입력을 없앤다.

### 화면 구성

| 영역 | 정부 상품 | 은행 상품 |
| --- | --- | --- |
| 헤더 | 상품명, 키워드 태그 | 상품명, 키워드 태그 |
| 요약 | 주관 기관, 저축 기간, 월 납입 가능액 | 금융회사, 저축 기간, 월 납입 한도 |
| 수익 하이라이트 | 기여금 연 환산 수익률, 예상 만기 기여금 총액 | 기본금리, 최고금리, **내가 받을 수 있는 금리** |
| 수익 분해 | 매칭 유형(정률/정액), 내 월 납입액, 저축 기간 | |
| CTA | 신청 아웃링크, 모집 기간 | 신청 아웃링크, [수익률 계산기] (모달) |
| 상품 안내 | 유형, 기간, 납입액, 가입 방법, 가입 대상(자격 요건), 유의 사항 | 동일 |
| 금리 안내 (스크롤 시) | **기본·우대금리가 공시된 상품만** 기간별 금리표, 우대조건, 이자 방식. 미공시 상품은 숨김 | 기간별 기본·최고 금리표, 우대조건, 이자 방식(단리/복리) |

정부 상품 중 금리가 공시된 상품(예: 청년내일저축계좌)도 금리 안내를 보여주지만, 정렬·비교 기준은 여전히 기여금 환산 수익률이다. 금리는 참고용이다.

### 기능 요구사항

1. **유형별 분기**: 상품 유형(POLICY/SAVING/DEPOSIT)과 출처(ONTONG/FSS)로 정부형·은행형 템플릿을 고른다. 그룹 2(공제부금형)는 리스트에 없으므로 상세 진입도 막는다.
2. **리스트 값 재사용**: 상세의 환산 수익률과 "내가 받을 수 있는 금리"는 리스트(Y3-2)에서 쓴 값과 같아야 한다. 상세에서 다른 방식으로 다시 계산하지 않는다(불일치 방지).
3. **비로그인 잠금**: 수익 지표 3종과 계산기 버튼은 비로그인 시 잠근다. 잠긴 영역을 누르면 같은 모달 컴포넌트에서 트리거별 문구를 보여준다.
   - 수익 지표: "내가 받을 수 있는 금리·기여금 환산 수익률·예상 만기 기여금 총액은 로그인 후 단계2 정보를 입력하면 확인할 수 있어요"
   - 계산기: "수익률 계산기는 로그인 후 이용할 수 있어요"
   - 로그인 후에는 클릭했던 위치로 돌아온다.
4. **찜 버튼**: 상세에 관심 상품 저장(하트) 버튼을 둔다(26-06-24 추가).

### 지표

- 북극성: 상세 도달 사용자의 아웃링크 전환율 30% 이상
- KPI: 수치 노출 후 즉시 이탈 15% 이내, 은행 상세에서 계산기 진입 40% 이상, 유형별 아웃링크 전환 30% 이상

## Y4-1 수익률 계산기

### 개요

은행 상품 상세에서 계산기를 열면, 1·2단계 입력으로 미리 채운 폼에서 과세 유형과 금리만 조정해 **만기 세후 실수령액**을 바로 계산한다. 은행 상품에만 있고, 비로그인 시에는 쓸 수 없다.

### 입력과 출력

| 항목 | 예금 (거치식) | 적금 (적립식) | 수정 |
| --- | --- | --- | --- |
| 적용 금리 | 기본 + 충족 우대금리 (0% ~ 상품 최고금리) | 동일 | 가능 ("계산 금리 수정하기") |
| 금액 | 예치금 1만 원 ~ 상품 최대 한도, 연동값 없음 | 월 납입액 1만 원 ~ 월 한도, 기본값은 1단계 월 납입 희망액 | 가능 |
| 저축 기간 | 상품 `save_trm` 옵션 드롭다운 | 동일 | 가능 |
| 이자 방식 | 상품 `intr_rate_type` (단리/월복리) | 동일 | 불가 |
| 적립 방식 | | 상품 `rsrv_type` (정액/자유) | 불가 |
| 과세 유형 | 일반 15.4% / 비과세 0%, 기본값 일반 | 동일 | 가능 |
| 출력 | 원금, 세전 이자, 이자 과세, 세후 실수령액 | 납입 원금 합계, 세전 이자, 이자 과세, 세후 실수령액 | |

세금우대 9.5%, 저율과세 1.4%는 조건을 충족해야 하는 특수 케이스라 반영하지 않는다.

### 산식

`r` = 연이율(소수), `n` = 개월 수, `i = r / 12`, `t` = 과세율(0.154 또는 0)

```text
[예금 단리]   세전이자 = P × r × (n / 12)
[예금 월복리] 만기금액 = P × (1 + i)^n,  세전이자 = 만기금액 − P

[적금 단리]   세전이자 = A × i × n(n + 1) / 2          (매월 초 납입, 회차별 등차합)
[적금 월복리] 만기금액 = A × (1 + i) × ((1 + i)^n − 1) / i,  세전이자 = 만기금액 − A × n

[공통]        이자과세 = 세전이자 × t
              세후 실수령액 = 원금(또는 납입원금) + 세전이자 − 이자과세
```

자유적립식도 "매월 초 동일액 납입"을 가정해 정액식과 같은 산식을 쓴다. 이 가정과 "실제 납입 시점·금액에 따라 수령액이 달라질 수 있음"을 결과 영역에 항상 표시한다(금소법상 오인 유발 방지).

### 지표

- 북극성: 계산기 사용자의 아웃링크 전환율이 미사용자의 1.5배 이상
- KPI: 은행 상세 도달자 중 계산기 사용 40% 이상, 결과 확인까지 70% 이상, 프리필 값을 수정하지 않고 계산한 비율

## Y4-2 아웃링크 신청

### 개요

상세에서 결정을 마친 사용자를 **기관 공식 신청 페이지로 1클릭 연결**하고, 클릭을 신청 전환 지표로 잰다(KPI: 추천 상품 신청률 15%, 클릭 기준 프록시).

Y-Fin.은 판매·중개 주체가 아니다(정보 제공·광고). 외부 아웃링크 구조, 비중개 고지, 은행 로고 미사용으로 금소법상 중개 재분류 리스크를 막는다. 아웃링크는 공개 정보라 비로그인에도 누를 수 있다.

### 데이터 현실

391개 상품 기준 `apply_url` 보유율은 온통청년 85.7%(54/63), 금감원 0%(0/328)다. 은행 상품은 API만으로 링크를 만들 수 없어 수동 매핑이 필요하다.

### URL 해소 우선순위

| 순위 | 조건 | 결과 |
| --- | --- | --- |
| 1 | 정부 상품 + `apply_url` 있음 | API 링크 직접 사용 |
| 2 | 정부 상품 `apply_url` 없음 | 매핑 테이블로 보완하거나 비활성 |
| 3 | 은행 상품 + 상품 코드 매핑 있음 | 상품 단위 링크 |
| 4 | 은행 상품 상품 코드 매핑 없음 | 은행 대표 URL (18개 은행) |
| 5 | 모두 없음 | 버튼 비활성 + "기관 공식 채널에서 신청" 안내 |

해소는 단일 함수로 만들고, 반환값에 해소 단계(`resolution_level`)를 넣어 매핑 품질을 측정한다.

은행 매핑 테이블 초안: `product_code`(PK), `provider_code`(폴백 키), `apply_url`, `terms_url`, `last_checked`, `is_valid`. 은행 대표 URL 18건을 먼저 확보해 폴백을 보장하고 상품 단위 링크는 점진적으로 늘린다. 깨진 링크는 정기 점검으로 `is_valid=false`가 되어 폴백으로 내려간다.

### FE 요구사항

- `target="_blank" rel="noopener noreferrer"`로 새 탭 이동
- CTA 하단 고지: "Y-Fin은 해당 상품의 판매·중개 주체가 아니며, 신청은 기관 공식 페이지에서 진행됩니다."
- 출처별 라벨: 정부 "사업 공고에서 신청", 은행 "은행 공식 페이지에서 신청"
- 이벤트 `apply_outlink_click` (속성: `product_id`, `source_code`, `resolution_level`, `is_logged_in`, `entry_point`). 외부 이동 후 실제 가입 여부는 추적하지 않는다.
