# Y3-1 정보 입력

> 원본: 노션 「Y3-1 정보 입력 기능 PRD」, 「Y3-1 정보 입력 항목 명세」(docx), 「Y3-1 정보 필수/선택 입력 분류」, 「Y3 우대조건 체크리스트」, 「UI/UX 업데이트 이력」(26-06-24)

## 개요

청년 정책 상품은 나이, 지역, 소득, 가구 소득 같은 정보가 있어야 자격을 판정할 수 있다. 하지만 처음부터 이걸 요구하면 사용자가 이탈한다. 그래서 입력을 두 단계로 나눈다.

- **1단계 (비로그인 가능)**: 태그 클릭만으로 대략적인 페르소나를 파악한다. 탭 A(적합도) 리스트를 바로 보여준다.
- **2단계 (로그인 후)**: 수치형 정보를 받아 자격 필터를 정밀하게 하고 탭 B(달성 가능 금리)를 연다.

본질은 "가장 적은 입력으로 가장 정확한 데이터를 확보하는 것"이다. 1단계 선택값은 로그인 뒤에도 유지해(브라우저 저장소 활용) 2단계 폼 기본값으로 채운다. 1단계 은행 거래 키워드는 2단계 우대조건에 그대로 반영한다.

## 필수/선택 분류 기준

**미입력 시 정렬값을 산출할 수 없으면 필수, 정밀도만 떨어지면 선택.**

### 1단계

| 항목 | 비로그인 | 로그인 | 근거 | 선택 방식 | 값 |
| --- | --- | --- | --- | --- | --- |
| 월 납입 희망액 | 필수 | 필수 | 분석 트리거, 납입 한도 대조 | 슬라이더 + 직접 입력 | 1만~100만 원, 기본값 30만 원 |
| 저축 기간 | 필수 | 필수 | 미선택 시 상품 중복 노출 | 단일 | #1년_내외 / #2~3년 / #3년_초과 |
| 은행 우대 조건 | 선택 | 필수 | 탭 B 달성 가능 금리 산출 | 복수 | #자동이체_우대 / #카드실적_우대 / #급여이체_우대 / #마케팅_동의_OK |
| 현재 신분 | 선택 | 선택 | 선택 시 가중치 반영, 자격 필터 | 단일 | #미취업 / #알바·프리랜서 / #중소기업_재직 / #군복무 |
| 핵심 혜택 | 선택 | 선택 | 적합도 가중치 | 복수 | #최고이율_중심 / #비과세 / #우대조건_간편 / #정부기여금 |

`#내집마련`은 청약을 리스트 하단 별도 섹션으로 분리하면서 핵심 혜택에서 삭제했다(26-06-24).

### 2단계 (로그인 전용)

| 항목 | 분류 | 근거 | 입력 방식 | 범위 |
| --- | --- | --- | --- | --- |
| 생년월일 | 필수 | 연령 자격 | 연도 드롭다운 | 15~49세 (1976~2011년생) |
| 개인 연 소득 | 필수 | 기여금 매칭 구간, 소득 요건 | 숫자 입력 (만원/원 전환, 월급→연봉 환산) | 0원~1억 원 |
| 가구원 수 + 가구 소득 | 필수 | 중위소득 자격 | 가구원 수 스테퍼 + 금액 가이드 + 소득 구간 | 1~6인 이상, 중위소득 60/80/100/120/150/180% |
| 거래 이력 | 필수 | 탭 B 첫거래·재예치 우대 | 2단 체크박스 | 아래 참고 |
| 거주 지역 | 선택 | 지자체 상품에만 필요 | 드롭다운 | 17개 시도 |
| 근속 기간 | 선택 | 근속 요건 상품 | 슬라이더 + 첫 직장 체크 | 0~120개월 |
| 무주택 여부 | 선택 | 청약·주거 상품 | 토글 + 세대주 후속 질문 | |

생년월일 범위는 원래 19~34세(군필 39세)였으나, 정부 상품 데이터의 최소·최대 연령을 반영해 15~49세로 넓혔다(26-06-24).

UI 규칙: 필수 항목은 레이블 옆 `*`와 "필수 입력 항목입니다." 문구. 2단계 선택 항목은 미선택 시 [건너뛰기], 선택 시 [다음 단계]. 필수 항목은 미입력 시 [다음 단계] 비활성.

## 동적 입력 규칙

| 조건 | 변화 |
| --- | --- |
| 1단계 `#미취업` 선택 | 2단계 근속 기간 숨김, 개인 연 소득 0원 기본값(수정 가능) |
| 가구원 수 변경 | 가구 소득 구간의 금액 가이드를 해당 가구원 수 기준으로 갱신 |
| 거래 이력 입력 완료 | 1단계 은행 우대 키워드에 더해 첫거래·재예치 우대를 자동 활성 |
| 거주 지역 미입력 | 거래 이력에서 지방은행 전체 노출 |

삭제된 규칙(26-06-24): `#미취업` 선택 시에만 연 소득 0원 자동 입력하던 규칙, `#군복무` 선택 시 생년월일 상한을 39세로 넓히던 규칙.

## 은행 우대조건 체계

시중 예적금 우대조건은 6개 공통 카테고리로 정리된다: 비대면 가입, 재예치, 주거래(급여이체·자동이체·카드실적 등), 첫거래, 연령, 타상품가입·실적. Y-Fin.은 이 중 5개를 입력이나 자동 처리로 매칭한다.

| 입력 단계 | 항목 | 표준 분류 |
| --- | --- | --- |
| 1단계 키워드 | #자동이체_우대 | 주거래(자동이체) |
| | #카드실적_우대 | 주거래(카드실적) |
| | #급여이체_우대 | 주거래(급여이체) |
| | #마케팅_동의_OK | 표준 외 빈출 |
| 2단계 거래 이력 | 거래한 적 없는 은행 | 첫거래 |
| | 만기 예적금이 있는 은행 | 재예치 |
| 자동 처리 | 비대면 가입 | 모든 사용자 자동 매칭 (청년은 사실상 모바일 가입) |
| | 연령 | 생년월일로 만 19~34세 자동 매칭 |

타상품가입·실적은 MVP에서 제외한다. 나중에 "이 은행 다른 상품이 있으면 금리 n% 더" 토글로 보여주는 안이 있다.

거래 이력은 "주거래 은행"을 직접 묻는 대신 "거래한 적 없는 은행"과 "만기 예적금이 있는 은행"을 묻는다. 인지 부담이 더 작기 때문이다. 질문 2는 질문 1에서 고르지 않은 은행만 보여준다.

## 거래 이력 은행 목록 (제1금융권)

| 구분 | 은행 | 거래 이력 노출 | 추천 결과 포함 |
| --- | --- | --- | --- |
| 시중은행 | KB국민, 신한, 하나, 우리, iM뱅크, SC제일, 한국씨티 | 씨티 제외 (신규 예적금 불가) | 씨티 제외 |
| 인터넷은행 | 케이뱅크, 카카오뱅크, 토스뱅크 | 전체 | 전체 |
| 특수은행 | NH농협, Sh수협, IBK기업, KDB산업, 수출입 | 수출입(개인 예적금 없음), 산업(우대이율 없음) 제외 | 수출입 제외 |
| 지방은행 | BNK부산, 광주, 제주, 전북, BNK경남 | 거주 지역 연동 | 전체 |

지방은행 노출 규칙: 부산→BNK부산, 광주·전남→광주, 전북→전북, 경남→BNK경남, 제주→제주. 그 외 지역은 지방은행 슬롯을 숨기고, "지방" 탭을 누르면 5개를 모두 보여준다. 결과적으로 1차 노출 12~13개, 2차 노출 18개, 추천 대상 18개 은행이다.

## 입력 항목과 원천 데이터 매핑

자격 판정과 점수 계산에 쓰는 공공 API 필드다. 백엔드는 수집기가 이 필드를 정규화해 만든 컬럼을 쓴다([데이터 모델](../implementation/data-model.md)).

| 입력 항목 | 온통청년 API | 금감원 API |
| --- | --- | --- |
| 월 납입 희망액 | (자체 한도 비교) | `max_limit` |
| 저축 기간 | `plcySprtCn` 텍스트 | `save_trm` (6/12/24/36개월) |
| 현재 신분 | `jobCd`, `schoolCd`, `addAplyQlfcCndCn` | `join_member`, `join_deny` |
| 핵심 혜택 | `plcyKywdNm`, `plcySprtCn` | `intr_rate2`, `spcl_cnd` |
| 은행 우대 조건, 거래 이력 | | `spcl_cnd` |
| 거주 지역 | `zipCd` | (지역 필터 없음) |
| 생년월일 | `sprtTrgtMinAge`, `sprtTrgtMaxAge`, `sprtTrgtAgeLmtYn` | `join_member` 텍스트 |
| 개인 연 소득 | `earnMinAmt`, `earnMaxAmt`, `earnCndSeCd` | |
| 가구 소득 | `earnEtcCn` (중위소득 기준 텍스트) | |
| 근속 기간, 무주택 | `addAplyQlfcCndCn` | |

API 참고:

- 온통청년 `https://www.youthcenter.go.kr/go/ythip/getPlcy`. 그 밖의 주요 응답 필드: `aplyUrlAddr`(신청 URL), `plcyAplyMthdCn`(신청 방법), `sprvsnInstCdNm`(주관 기관), `ptcpPrpTrgtCn`(참여 제한 대상).
- 금감원 금융상품한눈에 `depositProductsSearch.json`(예금), `savingProductsSearch.json`(적금). `topFinGrpNo` 020000=은행, 030300=저축은행. `optionList`에 `intr_rate_type`(단리/복리), `intr_rate`(기본), `intr_rate2`(최고), `rsrv_type`(정액/자유 적립).

## 지표

- 북극성: 랜딩 유입 대비 수동 입력 완료율 25% 이상
- KPI: 키워드 선택부터 수동 입력 완료까지 60초 이내, 단계 사이 이탈 15% 이내, 입력값이 정책 상품 유효 범위 안에 드는 비율
- 보조: 키워드별 가입 전환율, 필드별 체류 시간
