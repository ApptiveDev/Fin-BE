# Y3-2 추천 리스트 (필터링·정렬)

> 원본: 노션 「Y3-2 리스트 기능 PRD」, 「Y3-2 필터링-정렬 로직 명세」(v2.4), 「Y3-2 정부 상품별 수익률 계산 명세」

## 개요

사용자 입력으로 **가입 가능한 상품만 걸러내고**, 정부 상품과 시중은행 상품을 **탭 A "나에게 맞는 순"**, **탭 B "내가 받을 수 있는 금리 순"** 두 가지로 정렬해 보여준다. 정부·은행·지자체 사이트를 돌며 자격을 대조하는 피로를 없애는 것이 목적이다.

설계 전제:

- MVP 상품 범위: 정부 청년정책 예적금·청약(온통청년 API) + 시중은행 예적금(금감원 API)
- 자격 필터는 Hard Filter: 하나라도 미충족이면 리스트에서 완전히 제외한다
- 적합도 가중치는 설문 Q12 결과로 정부·은행에 비대칭 배분한다
- 정부와 은행은 점수·지표 기준이 달라 한 줄로 섞지 않는다(섹션 분리)

```text
[1차] 자격 요건 필터링   2단계 입력 + 1단계 신분·월 납입액 → 가입 불가 상품 제외
[2차] 정렬              탭 A: 키워드 매칭 점수 (100점)
                       탭 B: 정부 = 기여금 환산 수익률 / 은행 = 달성 가능 금리
```

## 탭 활성화 조건

| 상태 | 탭 A | 탭 B | 은행 거래 매칭 |
| --- | --- | --- | --- |
| 비로그인 (1단계만) | O | 비활성 ("로그인 후 활성" 안내) | 1단계 키워드 4개만 |
| 로그인 + 2단계 거래 이력 입력 | O | O | 1단계 키워드 + 첫거래·재예치 추론 |

## 1차: 자격 요건 필터 (공통)

| 단계 | 항목 | 판정 |
| --- | --- | --- |
| 2단계 | 거주 지역 | 해당 지역 정책만. 은행 상품은 지역 필터 없음(전국) |
| 2단계 | 생년월일 (만 나이) | 상품 최소 연령 ≤ 나이 ≤ 최대 연령 |
| 2단계 | 개인 연 소득 | 상품 소득 상한 이하 |
| 2단계 | 가구 소득 (가구원 수 연동) | 상품의 중위소득 기준 이하 |
| 2단계 | 근속 기간 | 상품 근속 요건 이상. `#미취업`이면 근속 요건 상품 자동 제외 |
| 2단계 | 무주택 여부 | 무주택·세대주 요건 (청약 필수) |
| 1단계 | 현재 신분 | 상품 가입 대상·제한 조건 매칭 |
| 1단계 | 월 납입 희망액 (하한) | 희망액 < 상품 최소 납입액이면 제외. 필터에만 쓰고 점수에는 반영하지 않는다 |

특수 규칙:

- **연 소득 0원**은 "소득 증빙 불가"로 보고, 소득 요건이 있는 상품을 제외한다.
- 종료·단종 상품(청년도약계좌 2025-12 단종, 청년희망적금 등)은 자동 제외한다.
- 리스트 상단에 "총 OO개 상품 중 자격 미충족 XX개 제외"를 보여준다. 설문에서 "신청 가능한 것만 보이게" 요구가 있었고, 필터가 동작한다는 걸 사용자가 알아야 신뢰가 생긴다.

## 탭 A: 나에게 맞는 순 (100점)

### 정부 상품 배점

| 항목 | 배점 | 산출 |
| --- | --- | --- |
| 핵심 혜택 | 40 | `40 × (매칭 수 / 선택 수)`. #정부기여금·#비과세는 지원 내용 텍스트, #우대조건_간편은 우대조건 3개 이하 |
| 저축 기간 | 22 | 정확 일치 22, 인접 구간 11, 불일치 0 |
| 현재 신분 특화도 | 20 | 신분 특화 상품 20 (예: #군복무 → 장병내일준비적금), 신분 포함 상품 10 |
| 납입 한도 적합도 | 18 | 희망액 ≤ 최대 한도면 18, 넘으면 `18 × (최대 한도 / 희망액)` |

v2.4에서 정부 상품의 "은행 거래 조건 8점"을 삭제하고 나머지 4개 항목에 재배분했다. 탭 B에서 정부 상품을 기여금 환산 수익률로만 비교하기로 하면서 은행 우대금리가 비교 근거를 잃었기 때문이다. 1·2단계의 우대금리 입력은 은행 상품 매칭에만 쓴다.

### 은행 상품 배점

| 항목 | 배점 | 산출 |
| --- | --- | --- |
| 은행 거래 조건 | 40 | `40 × (매칭 수 / 선택 수)`. 상품 우대조건(`spcl_cnd`)과 매칭 |
| 핵심 혜택 | 20 | #최고이율_중심(최고금리 상위 30%), #우대조건_간편(우대조건 3개 이하)만 적용 |
| 저축 기간 | 20 | 정확 일치 20, 인접 10, 불일치 0 |
| 납입 한도 적합도 | 15 | 희망액 ≤ `max_limit`면 15, 넘으면 `15 × (max_limit / 희망액)` |
| 현재 신분 특화도 | 5 | 가입 대상 텍스트에 신분 키워드가 있으면 5 |

은행 거래 조건 매칭 키워드(`spcl_cnd` 텍스트):

| 사용자 조건 | 매칭 단어 |
| --- | --- |
| #자동이체_우대 | 자동이체, 자동납입, 자동저축 |
| #카드실적_우대 | 카드, 체크카드, 신용카드 |
| #급여이체_우대 | 급여, 월급, 급여이체 |
| #마케팅_동의_OK | 마케팅 동의, 광고 동의, 정보 수신 동의 |
| 첫거래 (자동) | 첫 거래, 신규 고객, 최초 거래. 거래 이력 없는 은행의 상품에서만 |
| 재예치 (자동) | 재예치, 재가입, 만기 후 가입. 만기 예적금 보유 은행의 상품에서만 |

### 저축 기간 구간

| 선택 | 정확 일치 | 인접 |
| --- | --- | --- |
| #1년_내외 | 6, 12개월 | 24개월 |
| #2~3년 | 24, 36개월 | 12개월 |
| #3년_초과 | 36개월 초과 | 36개월 |

### 선택 안 함 처리

- 키워드를 하나도 고르지 않으면 [다음 단계]에서 "키워드를 1개 이상 선택해주세요" 경고.
- 어떤 항목을 선택하지 않았으면 그 배점을 **나머지 유효 항목에 비례 재배분**해 100점 만점을 유지한다. 키워드를 적게 고른 사용자가 불리해지지 않게 하려는 것이다.
- 여러 항목이 동시에 빠지면 빠진 배점을 합산해 유효 항목에 한 번에 재배분한다.
- 은행 상품에 해당 없는 혜택(#정부기여금, #비과세)만 골랐다면 은행 상품의 혜택 배점도 재배분한다.

### 정렬과 표시

- 정부 섹션과 은행 섹션을 각각 점수순으로 정렬하고, 한 화면에 3개씩 동시에 노출한다(드래그로 각 섹션 확인). 교차 배치안은 채택하지 않았다.
- 카드에 매칭 점수(%)와 충족 키워드를 보여준다. 표시 우선순위: 월 납입액 충족 > 저축 기간 일치 > 핵심 혜택 > 신분 자격 > 우대조건 달성 가능.

## 탭 B: 내가 받을 수 있는 금리 순

정부 섹션(기여금 환산 수익률 순)과 은행 섹션(달성 가능 금리 순)을 나누고, 두 섹션의 기준이 다르다는 안내를 하단에 표시한다.

### 정부 상품: 기여금 환산 수익률

협약은행의 기본·우대금리는 공시되지 않아 추정치로만 채울 수 있다. 추정치를 같은 비교선에 두면 공정성이 깨지므로, 정부 상품은 **검증 가능한 단일 지표인 정부 기여금 환산 수익률**로만 비교한다.

| 그룹 | 성격 | 처리 |
| --- | --- | --- |
| 그룹 1 | 우대금리가 있는 은행 예적금형 (이자 발생) | 기여금 환산 수익률로 비교 |
| 그룹 2 | 본인+기업+지자체 공제부금 적립형 (예: 광주형 청년일자리 공제, 경주형 내일채움공제) | 추천 범위 제외. 청년·기업 협의 후 기업이 신청하는 상품 |
| 그룹 3 | 청약 | 금리 비교 대상 아님. 리스트 하단 별도 섹션 ("청약: 금리 비교 대상 아님") |

산식은 매칭 유형별로 나눈다. 단순 평균법이라 정률 매칭은 납입액과 무관하고, 정액 매칭은 납입액이 적을수록 수익률이 오른다. 단기 상품일수록 환산 금리가 부풀려지는 한계도 있다.

```text
매칭 배수 = 외부(정부·지자체·기업) 매칭 총액 / 본인 납입 총액

정률 매칭: 환산 수익률(연%) = 매칭 배수 / 가입기간(년) × 100
정액 매칭: 환산 수익률(연%) = (월 정액 매칭 / 본인 월 납입) / 가입기간(년) × 100
```

예시:

- 부산 기쁨두배통장 1:1, 2년 → 1.0 / 2 × 100 = 연 50%
- 청년내일저축계좌 (월 30만 원 정액, 3년), 본인 월 10만 원 → 100%, 30만 원 → 33.3%, 50만 원 → 20%
- 청년미래적금 일반형 (납입액의 6%, 3년) → 0.06 / 3 × 100 = 연 2.0%, 우대형 (12%) → 연 4.0%

상세 화면에는 "예상 만기 기여금 총액"(외부 매칭 총액)도 함께 보여준다.

기획 시점에 조사한 값이다. 모집 일정과 조건은 매년 바뀌므로 실제 데이터는 수집 결과를 따른다.

### 은행 상품: 달성 가능 금리

```text
달성 가능 금리 = 기본금리(intr_rate)
              + 1단계 매칭 우대금리 (자동이체 / 카드실적 / 급여이체 / 마케팅 동의)
              + 자동 처리 우대금리 (비대면 가입 / 연령)
              + 2단계 거래 이력 우대금리 (첫거래 / 재예치)
```

사용자가 체크하지 않았거나 상품에 해당하지 않는 우대금리는 더하지 않는다. 광고 최고금리는 쓰지 않는다.

| 항목 | 값 |
| --- | --- |
| 기본금리 | 3.5% |
| 우대: 급여이체 / 카드실적 / 첫거래 / 비대면 | +0.3 / +0.2 / +0.5 / +0.1 |
| 사용자 | #급여이체_우대만 체크, 해당 은행을 "거래 안 한 은행"으로 선택 |
| **달성 가능 금리** | **3.5 + 0.3 + 0.5 + 0.1 = 4.4%** (카드실적은 미체크라 제외) |

### 카드 표시

- 상품명, 유형 태그(정부·시중·청약)
- 굵은 숫자로 실질 수익률 또는 달성 가능 금리, 보조 텍스트로 기본금리
- 달성 가능한 우대조건을 출처별로(1단계 체크 / 자동 처리 / 거래 이력 추론) 구분 표시
- 세전·세후 수익 병기. 비과세 상품은 세금 0원과 비과세 뱃지 (설문 Q5 세후 실수령액 51%)

## 지표

- 북극성: 리스트 노출 대비 상세 진입률 60% 이상
- KPI: 탭 A↔B 전환 40% 이상, "자격 미충족 XX개 제외" 문구 클릭·호버 20% 이상, 비로그인 리스트 사용자의 로그인(탭 B 활성화) 전환 30% 이상
- 보조: 상위 5개 상품 적합도 분산(너무 작으면 가중치 변별력 부족), 종료 상품 노출 0건, 탭 B 정부 vs 은행 상위 노출 비율
