# B1 정부상품 캘린더

> 상태: 기획 (미구현) · 원본: 노션 「B1 정부상품 캘린더 PRD」, 「B1 정부상품 캘린더 기능 명세」(2026-10-05), 「서비스 기획 피봇팅」

## 개요

- 정책 저축상품과 청년 금융 지원 정책의 모집 일정을 한 화면에 모은 캘린더. 리텐션 엔진의 '탐색' 축이고, B2 알림이 '복귀' 축이다.
- 배경: 정책 저축은 대부분 연 1~2회 단기 모집이다(예: 청년미래적금은 2026.6.22~7.3 첫 모집, 이후 매년 6월·12월). 청년 금융 지원 정책도 절반 이상이 한 달 안에 마감된다. 모집 기간을 놓치면 다음 회차까지 6개월~1년을 기다려야 하고, 일정은 기관별 공고에 흩어져 있다.
- 핵심 결정
  - 달력보다 '지금 신청 가능'을 먼저 보여준다.
  - 일정에서 바로 상세(Y4)와 알림 설정(B2)으로 잇는다. 신청은 Y4 상세에서만 한다(캘린더에는 신청 페이지 링크를 두지 않아 상세 확인 후 신청 클릭률을 측정).
  - 정책상품 16종만으로는 월 1~3건이라 밀도가 낮아, Y-Fin 상품 DB에 없는 청년 금융 지원 정책을 2계층으로 더한다.
  - 12/31에 일괄 종료되는 정책은 '연중 접수'로 분리해 12월에 가짜 마감이 몰리는 착시를 없앤다.
  - 비로그인도 열람 가능(신규 유입 랜딩 겸용). 로그인하면 내 자격과 내 만기를 반영한다.
- 9월 스코프에서 Batch 2 "리텐션 기능"(B1·B2·coming soon)에 속한다. 공수 판정은 "타이트".

## 범위

- 포함: 데스크톱 월간·리스트 뷰, 모바일 리스트·월간 뷰
- 제외: 주거 정책
- 우선순위: P0 출시 필수 / P1 출시 목표, 밀리면 fast-follow / P2 출시 후
- 선행 전제(피봇팅 문서): 캘린더는 라이브러리 활용 전제, 온통청년 API 날짜 필드는 W1에 검증

## 용어

| 용어 | 정의 |
| --- | --- |
| 회차 | 한 정책의 모집 1회. 신청 시작일과 종료일을 가진다 |
| 일정 | 캘린더에 찍히는 날짜 항목. 회차 1개에서 `시작`, `마감` 일정 2개가 생긴다 |
| 지금 신청 가능 | 오늘이 회차 시작일~종료일 사이인 상태 |
| 내 조건 맞춤 | 로그인 유저의 자격 정보(나이, 소득, 거주지역 등)로 자격 없는 일정을 숨기는 필터 |
| 1계층 / 2계층 | Y-Fin 정책상품 / 청년 금융 지원 정책 (아래 데이터 계층) |

화면 ID 참고: Y3-1 정보 입력, Y3-2 추천 결과, Y4 상품 상세, Y4-2 신청 페이지, B2-xx는 B2 알림 화면.

## 데이터 계층

| 항목 | 1계층: Y-Fin 정책상품 | 2계층: 금융 지원 정책 |
| --- | --- | --- |
| 대상 | POLICY001~016 (16종) | 온통청년 정책 중 자산형성 저축, 공제, 신용회복 등 |
| 상품명 클릭 | Y4 상세 | 온통청년 정책 상세 (새 탭) |

| 자격 판정 | Y3-2 자격 필터 그대로 (나이, 소득, 거주지역, 군 복무 연장) | 나이, 거주지역만 (정책별 소득 조건이 정형화되어 있지 않음) |

- 1계층 16종은 온통청년 정책과 연결 키가 없어 운영자가 승인한 회차만 노출한다.

## 일정 유형과 판정 규칙

| 일정 유형 | 정의 | 캘린더 표시 |
| --- | --- | --- |
| 신청 시작·마감 | 회차의 신청 시작일·종료일 | `시작`, `마감` 칩. 마감 7일 이내면 D-n |
| 모집 예정 | 공식 발표는 있으나 공고 전인 회차 (운영자 입력) | 일자 확정이면 `예정` 칩, 미확정이면 월 배너 |
| 연중 접수 | 모집 기간 180일 이상이면서 12/31 종료 | 그리드 미표시, 별도 목록 |
| 상시 신청 | 신청 기간이 따로 없는 정책 | 그리드 미표시, 별도 목록 |
| 내 만기 | 본인이 B2에서 등록한 가입 상품의 만기일 | `만기` 칩 (등록한 본인에게만) |

판정 순서

1. 모집 기간 180일 이상 그리고 12/31 종료 → 연중 접수. 마감 칩 없음. 시작일이 미래면 시작 칩만.
2. 그 외 특정기간 → 시작 칩, 마감 칩.
3. 운영자가 입력한 예정 회차 → 일자 확정은 예정 칩, 미확정은 월 배너.
4. 유저가 등록한 가입 상품 → 내 만기 칩(본인만).

- 예시: 10.01~10.08은 시작·마감 칩 / 01.01~12.31은 연중 접수 / 09.01~12.31(122일)은 180일 미만이라 마감 칩 표시 / 시작일과 종료일이 같으면 마감 칩만.

온통청년 신청기간 구분별 처리

| 구분 | 처리 |
| --- | --- |
| 특정기간 | 시작·마감 일정 생성 |
| 상시 | 그리드 미표시, '상시 신청 n건' 목록 |
| 마감 | 표시하지 않음. 이미 보이던 회차는 종료 처리 |

- 한 정책에 회차가 여러 개면 회차마다 따로 저장·표시한다.
- 신청기간 값을 읽을 수 없는 정책은 표시하지 않고 운영 확인 목록으로 보낸다.

### 1. 월간 캘린더 (P0)

- 1·2계층 정책의 시작·마감 일정을 회차 단위로 표시한다.
- 일정 칩 구성: 유형 라벨 + 상품명 + (마감 7일 이내) D-n.
  - 유형 라벨(`시작`, `마감`, `예정`, `만기`)은 색만으로 구분하지 않고 텍스트를 반드시 붙인다.
  - 2계층은 상품명을 보조 톤으로 처리해 1계층과 구분한다.
  - 로그인 유저가 알림을 설정한 일정은 유형 라벨 뒤에 알림 표시.
  - 긴 상품명은 칩에서 한 줄 말줄임, 카드에서 두 줄까지.
- 칸 안 정렬: 내 만기 → 마감(남은 일수 적은 순) → 시작 → 예정. 같은 유형이면 1계층 먼저.
- 한 칸에 칩 3개까지, 넘치면 `+n건`. `+n건`을 누르면 그 날짜를 선택하고 우측 패널에 그날 목록.
- 데스크톱 호버 미리보기: 상품명, 신청 기간, D-day, [상세 보기] (2계층은 [온통청년 보기]).
- 월 이동 범위: 오늘 기준 이전 3개월 ~ 이후 12개월. 한도 문구 `1년 뒤 일정까지 볼 수 있어요`.

D-day 표기와 강조 3단계

| 남은 일수 | 표기 | 강조 |
| --- | --- | --- |
| 0 | `오늘 마감` | 가장 강함 |
| 1~3 | `D-1` ~ `D-3` | 가장 강함 |
| 4~7 | `D-4` ~ `D-7` | 중간 |
| 8 이상 | `D-12` 형식 (카드·리스트에서만, 칩에는 미표기) | 기본 |

- 종료일 당일 자정까지 `오늘 마감`. 다음 날이 되면 '지금 신청 가능'에서 빠진다.
- 날짜 기준은 한국 시간.

### 2. 요약 카운터·지금 신청 가능 (P0)

| 카운터 | 정의 | 기준 |
| --- | --- | --- |
| 지금 신청 가능 | 오늘이 시작일~종료일 사이인 회차 수 | 오늘 (보고 있는 월과 무관) |
| 마감 임박 | 위 중 마감까지 7일 이하 | 오늘 |
| 이번 달 시작 | 시작일이 보고 있는 월에 있는 회차 수 | 보고 있는 월 |
| 설정해둔 알림 (로그인) | 내가 설정한 알림 수 | |

- 모든 카운터와 칩 건수는 현재 필터를 반영한다. 0이어도 숨기지 않는다.
- 비로그인은 3칸, 로그인은 4칸.
- 우측 패널 ① '지금 신청 가능'
  - 행 구성: `진행 중`, 상품명, 마감일, 기관, D-day, 이동 화살표. 마감 가까운 순 3건.
  - 행을 누르면 Y4 상세(2계층은 온통청년). 신청 페이지로 바로 가지 않는다.
  - 3건을 넘으면 `전체 n건`으로 접고, 누르면 '지금 신청 가능' 필터가 걸린 리스트 뷰로 이동.
  - 0건이면 `지금 신청할 수 있는 정책이 없어요` + 가장 가까운 시작 일정 1건.

### 3. 우측 패널·일정 상세 카드 (P0)

- 패널은 모든 화면에서 ① → ② → ③ → ④ 순서로 쌓고, 해당 없는 섹션은 뺀다.
  - ② 선택 날짜 일정: 기본 선택은 오늘. 여러 건이면 선택한 1건만 펼친다. 일정 0건인 달은 '가장 가까운 다음 일정'으로 바뀐다(B1-04).
  - ③ 내 만기: 로그인 + 등록한 가입 상품이 있을 때만.
- 일정 상세 카드 (위에서부터)

| 순서 | 정보 | 비고 |
| --- | --- | --- |
| 1 | 유형과 D-day, 계층 배지, 찜(1계층), (바뀐 경우) `일정 변경` | 일정 변경 배지는 7일간 |
| 2 | 상품명, 기관, 한 줄 설명 | |
| 3 | 신청 기간, 대상, (로그인) `내 조건 맞춤` 결과 | `충족` 또는 `미충족`만. 근거는 내 조건 패널에서 확인 |
| 4 | [상세 보기] (2계층은 [온통청년 보기]), 알림 버튼 | 알림 버튼 상태는 B2 문서의 B2-04 |
| 5 | 데이터 기준일 | 예: `온통청년 10.05 기준` |

- 카드에는 신청 페이지로 바로 가는 링크를 두지 않는다.
- 2계층 카드는 찜과 [상세 보기]를 빼고 [온통청년 보기](새 탭), 알림 버튼만 둔다.
- 예외: 오늘 조기 종료된 회차는 카드에 `모집이 종료됐어요` 표시 후 다음 갱신 때 제거 / 프로필 값이 빈 조건은 자격 결과 자리에 `정보 입력 필요`, [입력하기].
- 헤더 [내 알림]은 B2-05로 이동, 비로그인은 로그인 유도 모달.

### 4. 필터·내 조건 맞춤 (P0)

| 필터 | 선택 방식 | 규칙 |
| --- | --- | --- |
| 신청 기간 | 다중 선택 | 전체, 신청 시작, 신청 마감, 모집 예정, 내 만기. `전체`를 누르면 나머지 해제, 마지막 하나를 끄면 `전체`로 복귀. 칩에 건수 |
| 상품 분류 | 단일 선택 | 전체, Y-Fin 정책상품, 금융 지원 정책 |
| 내 조건 맞춤 | 토글 (내 조건 패널 안) | 로그인만. 기본 ON. 켜면 거주지역 포함 내 자격 정보로 거르고, 끄면 전국 전체 |

- 내 조건 맞춤 ON이면 자격 없는 일정을 숨긴다. 적용 조건은 데이터 계층 표의 자격 판정 참고. 프로필 값이 빈 조건은 통과시키고 카드에 `정보 입력 필요`.
- 지역은 따로 고르지 않는다. 내 자격 정보의 거주지역을 그대로 쓰고, 바꾸려면 [내 정보 수정]. 전국 대상 정책은 항상 포함.
- 지역 기준: 비로그인은 전국, 로그인은 맞춤 ON이면 거주지역, OFF면 전국.
- 내 조건 버튼·패널

| 항목 | 규칙 |
| --- | --- |
| 버튼 (닫힘) | 맞춤 ON: `내 조건 맞춤`(체크) / OFF: `내 조건 맞춤 꺼짐` / 비로그인: `내 조건으로 보기` 잠금 |
| 중복 표시 금지 | 지역·나이를 버튼과 카드에 반복하지 않음. 지역은 한 줄 요약에서 한 번, 자격 정보는 패널에서만 |
| 패널 (열림) | ① `내 조건 맞춤` 토글 ② 내 자격 정보(나이, 소득, 거주지)와 `내 정보 수정` |
| 적용·닫기 | 토글 즉시 반영, 적용 버튼 없음. 버튼 재클릭이나 바깥 클릭으로 닫힘 |
| 모바일 | 버튼은 `내 조건 · {거주지역}`, 누르면 바텀시트 |

### 7. 빈 상태·연중·상시 일정 (P1)

빈 상태 (B1-04): 그리드는 지우지 않고 그 위에 안내 카드를 띄운다.

| 조건 | 문구 | 버튼 |
| --- | --- | --- |
| 내 조건 맞춤 ON, 0건 | `이번 달엔 내 조건에 맞는 모집 일정이 없어요` / `정책 저축상품은 대부분 1년에 1~2번만 모집해요. 다음 모집이 시작되면 놓치지 않게 알려드릴게요.` | [전체 일정 보기], [다음 모집 알림 받기] |
| 내 조건 맞춤 OFF, 0건 | `이번 달엔 예정된 모집 일정이 없어요` | [다음 일정 있는 달로 이동] |
| 다음 달 이후 모집 예정 있음 | 상단 배너, 예: `12월 모집 예정 · 청년미래적금 2차 모집이 12월 중 열릴 예정이에요` | |

- 0건인 달의 우측 패널 ②는 '가장 가까운 다음 일정'으로 바뀐다: 모집 예정, 다음 시작/마감 일정 최대 2건 + [n월로 이동].

연중·상시 일정

- 연중 접수·상시 신청은 그리드에 찍지 않고 우측 패널 ④로 보여준다.
  - 행: `연중 접수 중인 정책 n건` [보기] → B1-06 연중 접수 탭 / `상시 신청 가능 정책 n건` [보기] → B1-06 상시 신청 탭
  - 캡션 `연중 접수는 예산 소진 시 조기 마감될 수 있어요`
  - 0건인 행은 숨기고, 두 행 모두 0건이면 ④를 뺀다.
  - 모집 예정은 ④에 넣지 않는다(확정은 `예정` 칩, 미확정은 월 배너, 일정 없는 달은 ②).
- 드로어 (B1-06)

| 항목 | 규칙 |
| --- | --- |
| 형태 | 캘린더 위 오른쪽 드로어. 모바일은 전체 화면 |
| 탭 | `연중 접수 n`, `상시 신청 n`. ④에서 누른 행의 탭이 열림 |
| 필터 | 캘린더의 내 조건 맞춤·상품 분류를 그대로 적용. 신청 기간 필터는 적용하지 않음 |
| 정렬 | `{지역} 기준 · 최근 공고순` |
| 행 구성 | 유형, 계층 배지, 찜(1계층) / 상품명 / 기관, 신청 기간, 대상 / [상세 보기] (1계층) 또는 [온통청년 보기] (2계층) |
| 알림 버튼 | 없음. 드로어 설명에 `마감일이 없어 알림은 설정하지 않아요` 한 번 안내 |
| 닫기 | X, 바깥 클릭. 보던 월·필터 유지 |

## 데이터·API

### BE

- 일정 동기화: 온통청년 정책을 하루 1회 이상 수집하고, B2 오전 9시 발송 전에 완료한다. 한 정책의 여러 회차는 회차 단위로 분리 저장.
- 갱신 실패: 마지막 데이터를 유지하고 기준일을 실제 갱신 시각으로 표시.
- 일정 유형 판정: 신청기간 구분(특정기간, 상시, 마감)과 기간 길이로 시작, 마감, 연중 접수, 상시, 모집 예정을 판정(위 판정 규칙).
- 계층 선별·연결: 2계층은 청년 금융 지원 정책만 노출 대상으로 표시. 1계층 16종은 온통청년과 연결 키가 없어 운영자가 승인한 회차만 노출.
- 자격 판정: 1계층은 Y3-2 자격 필터 재사용, 2계층은 나이·거주지역만. 프로필 값이 비면 통과 처리하고 `정보 입력 필요` 플래그 반환.
- 일정 변경 감지: 동기화 때 날짜가 바뀐 회차에 `일정 변경` 표시(7일간)하고, B2에 알림 재조정 이벤트를 전달.
- 조회 API
  - 월별 일정, 칩 건수, 요약 카운터
  - 일정 상세
  - 지금 신청 가능, 연중·상시 일정, 가장 가까운 다음 일정
  - 내 만기 (로그인)
- 운영 도구: 1계층 회차 연결 승인, 모집 예정 입력, 신청기간을 읽을 수 없는 정책 확인 목록.

### FE

- 월간 그리드, 칩 호버 미리보기, 리스트 뷰, 우측 패널, 일정 상세 카드, 연중·상시 드로어(탭 2개, 캘린더 필터 적용)를 월간·리스트 모두 지원하는 구조로 구현.
- 필터 상태: 신청 기간 다중 선택(`전체`와 상호 배타), 상품 분류 단일 선택, 내 조건 토글을 한 상태로 묶어 카운터·칩 건수·그리드에 동시 반영.
