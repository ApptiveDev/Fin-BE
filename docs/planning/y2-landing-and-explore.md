# Y2 소개·탐색

> 원본: 노션 「Y2 소개/탐색 PRD」 · 대부분 프론트엔드 기능

## 개요

회원가입이 "통로"라면 소개·탐색은 그 통로로 들어오게 만드는 "쇼윈도"다.

- **소개 (Y2-1)**: 로그인 전 사용자가 처음 보는 스크롤형 랜딩 페이지. 스크롤만으로 "내 금융 고민을 해결해줄 곳"이라는 확신을 주는 것이 목적이다.
- **탐색 (Y2-2, Y2-3)**: 로그인 없이 서비스의 핵심 UI를 미리 써 보게 한다. 일부 기능은 제한하고, 제한 기능을 누르면 로그인 유도 모달을 띄운다.

배경: 진입 시 모든 기능을 막는 앱보다 핵심 가치 일부를 먼저 보여주는 앱의 전환율이 높다(점진적 정보 공개, NN/g Progressive Disclosure). 금융 초보는 "어떤 상품이 있나"보다 "나와 비슷한 사람은 뭘 보나"에 호기심이 크다.

## 소개 페이지 구성

4개 섹션을 순서대로 보여준다.

| 섹션 | 메시지 | 연출 |
| --- | --- | --- |
| 금융상품 추천 | "아직도 아무 상품이나 가입하세요? 30초 만에 찾는 청년 금융 소울메이트" / "단 세 단계로 나에게 맞는 금융상품" (조건 입력 → TOP3 → 상세 후 가입) | 카드 스택 애니메이션, 1→2→3 수직 타임라인 |
| 금융상품 상세 | "왜 이 상품이 나에게 최적인지, 조건과 수익률로 확인" | 가상 프로필과 우대조건 매칭 게이지 |
| 커뮤니티 | "또래들이 가장 많이 담은 상품 TOP 5" | 1위 크게, 2~5위 랭킹 보드 (P2) |
| 마이페이지 | "정보를 저장해뒀다가 더 좋은 상품을 알려드릴게요" | 위젯형 대시보드 |

- 각 섹션 하단과 최하단에 [3초 만에 시작하기] CTA를 두고, 누르면 로그인 플로우로 보낸다.
- 초안의 "약관 3줄 요약", "용어 챗봇" 섹션은 이후 기획에서 삭제·대체되었다(약관 요약 삭제, 용어는 전역 금융 용어 풀이로 대체).

## 탐색: 비로그인 권한 분기

로그인 여부를 전역에서 판별해, 제한 기능 진입 시 로그인 유도 모달을 띄운다. 라우팅 레벨에서 처리한다.

| 구분 | 범위 |
| --- | --- |
| 허용 | GNB 이동, Y1 가입·로그인, Y2-1 소개, Y3 1단계 키워드 선택과 리스트(탭 A), Y4 상세 공개 정보, 신청 아웃링크 |
| 제한 | Y3 2단계 수동 입력, 탭 B, Y4 개인화 수익 지표와 수익률 계산기, Y5 마이페이지 전체, 커뮤니티(P2) |

전체 허용 범위 표는 [기능 맵](feature-map.md#로그인-상태별-허용-범위)에 있다.

모달 UX: 배경 블러, "지금 로그인하면 당신을 위한 금융 상품을 찾아드려요!" 같은 개인화 문구.

## 공통 레이아웃

- GNB는 sticky. 비로그인 시 우측 상단에 [로그인/회원가입], 로그인 후 [마이페이지].
- FNB: 만든 사람들 링크, 문의 이메일, 서비스 이용약관 링크.

## 지표

- 북극성: 랜딩 진입 대비 추천 탭 클릭 전환율 35% 이상
- KPI: 랜딩 75% 지점 스크롤 도달률 50% 이상, 로그인 모달을 본 사용자의 가입 완료율 15% 이상, 로그인 전 GNB 클릭률
- 보조: 섹션별 체류 시간, 로그인 유도 모달 이탈률
